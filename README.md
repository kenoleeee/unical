# TikTok Video Uniquifier

## Что делает каждый этап обработки

| Этап | Техника | Результат |
|------|---------|-----------|
| Цветокоррекция | `eq` filter: яркость ±7%, контраст/насыщенность ±8% | Меняет RGB-значения всех пикселей |
| Zoom + Crop | Scale ×1.02–1.05 → Crop обратно | Смещает координаты пикселей |
| Шум | `noise=alls=3:allf=a+u` | Покадровый pixel-noise |
| Box-оверлей | `drawbox` с прозрачностью 6–15% | Уникальный визуальный элемент |
| Стикер | PNG-оверлей 90×90px, 45% opacity | Брендинг в углу |
| Перекодирование | H.264 CRF 23, FPS 29.97/25/23.976 | Новый контейнер и хэш |
| Аудио | AAC ресемплинг 44.1/48 кГц | Новый аудио-отпечаток |
| Метаданные | `-map_metadata -1` | Полная очистка EXIF/тегов |

## Запуск

```bash
cd ~/unical

# Только UI (рекомендуется)
./run.sh

# UI + API одновременно
./run.sh both

# Только API (docs на :8000/docs)
./run.sh api
```
